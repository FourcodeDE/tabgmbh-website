Anleitung: Signatur einrichten

Klicke oben auf „Signatur kopieren“ bei deinem Namen. Die Signatur wird dabei mit allen Formatierungen und Bildern in die Zwischenablage kopiert.

Outlook (Desktop) — Empfohlen: Download-Methode

Copy-Paste funktioniert in Outlook Desktop leider nicht zuverlässig, weil Outlook intern eine andere Darstellungs-Engine nutzt. Verwende stattdessen den „Outlook Download“-Button — damit sieht alles genauso aus wie im Entwurf.
  1. Klicke oben auf „Outlook Download“ bei deinem Namen — eine .htm-Datei wird heruntergeladen
  2. Öffne ein erstes Explorer-Fenster und gehe zu deinem Downloads-Ordner — dort liegt die Datei
  3. Öffne ein zweites Explorer-Fenster und gib oben in die Adresszeile ein:
    %APPDATA%\Microsoft\Signatures
    und drücke Enter — der Signatur-Ordner von Outlook öffnet sich (dort siehst du ggf. schon vorhandene Signatur-Dateien)
  4. Ziehe die .htm-Datei aus dem Downloads-Fenster in den Signatures-Ordner
  5. Öffne Outlook → Datei → Optionen → E-Mail → Signaturen
  6. Die Signatur erscheint jetzt in der Liste — wähle sie als Standard für „Neue Nachrichten“ und „Antworten/Weiterleitungen“
  7. Klicke auf OK — fertig!
Hinweis: In Outlook selbst werden die Ecken der Signatur eckig dargestellt — das ist eine bekannte Outlook-Einschränkung. Beim Empfänger (z.B. Gmail, Apple Mail, Handy) sieht die Signatur trotzdem korrekt mit abgerundeten Ecken aus.

Outlook (Web / Microsoft 365)

Im Web-Outlook funktioniert Copy-Paste problemlos:

  1. Klicke oben auf „Kopieren“ bei deinem Namen
  2. Klicke oben rechts auf das Zahnrad → Alle Outlook-Einstellungen anzeigen
  3. Gehe zu E-Mail → Verfassen und Antworten
  4. Füge die Signatur in das Textfeld ein (Strg+V)
  5. Aktiviere „Automatisch in neue Nachrichten einfügen“
  6. Klicke auf Speichern

Apple Mail (Mac)

  1. Öffne Apple Mail → Einstellungen → Signaturen
  2. Wähle dein E-Mail-Konto links und klicke auf +
  3. Klicke in das rechte Vorschaufeld und füge die Signatur ein (Cmd+V)
  4. Wähle unter „Signatur auswählen“ die neue Signatur
Falls Bilder nicht angezeigt werden: In Apple Mail → Einstellungen → Datenschutz → Haken bei „Entfernte Inhalte in Nachrichten laden“ setzen.

Apple Mail (iPhone/iPad)

  1. Öffne Einstellungen → Mail → Signatur
  2. Tippe in das Textfeld und füge die Signatur ein

Thunderbird

  1. Klicke auf das Hamburger-Menü → Kontoeinstellungen
  2. Wähle dein E-Mail-Konto links
  3. Aktiviere „HTML verwenden“ unter dem Signaturfeld
  4. Füge die Signatur in das Textfeld ein (Strg+V)
  5. Klicke auf OK

Webmail (Gmail, GMX, etc.)

  1. Öffne die Einstellungen deines Webmail-Anbieters
  2. Suche den Bereich Signaturen oder E-Mail-Signatur
  3. Erstelle eine neue Signatur und füge sie per Strg+V ein
  4. Speichern
